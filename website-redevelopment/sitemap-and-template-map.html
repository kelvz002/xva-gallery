Conversion pathways

  • New visitor: Homepage -> current exhibition -> Contact / directions.
  • Collector or client: Menu -> Artists or Art Consultancy -> artist/detail -> Contact.
  • Press: Menu -> Press -> release accordion or PDF -> Mona Hauser email.
  • Local visitor: Homepage -> Hotel & Café or Contact -> XVA Hotel / directions.
  • Returning audience: Newsletter form -> production mailing provider -> current programme.

Redirect recommendations

Keep all current public paths where possible. Consolidate only duplicate legacy routes after confirming canonical behavior in CMS. If /home/ or /home-new/ remains public, redirect to /; map /exhibitions-old/ to /exhibitions-new/; map /artists/ to /artists-list/ if it is not separately curated; preserve all /artist/[slug]/ and /exhibitions/[slug]/ routes.
